# Azure Static Website Deployment Lab

## Project Overview

This project documents my hands-on experience creating, configuring, and testing a static website using Microsoft Azure Blob Storage.

The purpose of this lab was to gain practical experience with cloud storage, static website hosting, basic web development, and cloud resource management.

**Project Status:** Completed — Azure resources decommissioned after testing.

## Technologies & Tools

- Microsoft Azure
- Azure Storage Account
- Azure Blob Storage
- HTML5
- CSS3
- Visual Studio Code
- GitHub
- AI-assisted design and development

## Project Objectives

- Create a basic static website using HTML and CSS.
- Customize the website layout and visual appearance.
- Integrate a custom image asset.
- Configure static website hosting in Azure.
- Upload website files to the Azure `$web` container.
- Access and test the website through its public Azure endpoint.
- Practice managing and decommissioning cloud resources.

## Implementation Process

### 1. Website Development

Created an HTML webpage using Visual Studio Code and CSS styling.

Customized the website with:
- A minimalist dark navy design.
- Blue and white visual accents.
- A custom cross image asset.
- Responsive layout styling.

### 2. AI-Assisted Design

Used AI tools to brainstorm design concepts, refine the website's appearance, generate a custom image asset, and assist with HTML and CSS development.

I directed the design decisions, implemented the code, and tested the resulting webpage.

### 3. Azure Configuration and Deployment

- Created an Azure Storage Account.
- Enabled Static Website Hosting.
- Configured `index.html` as the index document.
- Uploaded website files to the `$web` container.
- Accessed the website using the Azure primary endpoint.
- Tested website rendering and image integration.

### 4. Resource Management

After completing the deployment and testing process, I decommissioned the Azure resources to avoid unnecessary ongoing costs.

The website source files and project documentation were retained locally for GitHub version control.
