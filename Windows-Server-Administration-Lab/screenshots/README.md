# Windows Server Administration Lab — Screenshots

This folder contains visual evidence of the Windows Server Active Directory administration lab.

## Screenshot Guide

| Screenshot | What It Demonstrates |
|---|---|
| `server-manager.png` | Installation of Active Directory Domain Services (AD DS) and related administration tools |
| `active-directory-ous.png` | Active Directory domain structure and organizational units, including Finance, HR, IT, and Sales |
| `group-policy.png` | Group Policy Management Editor and security policy configuration |
| `removable-storage-policy.png` | Configuration of the policy **All Removable Storage classes: Deny all access** |
| `powershell-user-management.png` | PowerShell commands for managing Active Directory users, group memberships, passwords, and account status |
| `dns-delegation-warning.png` | DNS delegation warning encountered during domain controller configuration in the isolated lab environment |

## Skills Demonstrated

- Windows Server administration
- Active Directory Domain Services (AD DS)
- Organizational Unit (OU) management
- Group Policy configuration
- PowerShell administration
- User and group account management
- DNS configuration concepts
- Troubleshooting and interpreting installation warnings

## Evidence Notes

The screenshots document the lab setup and configuration process. Group Policy application to a test user or workstation has not yet been independently verified.

The DNS delegation warning was documented as part of the domain controller configuration process. In an isolated lab environment without an existing parent DNS zone, this warning may be expected.
